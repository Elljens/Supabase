# Supabase

## Description

This is a school project for Development platforms.
It combines a front-end application with Supabase as a back-end service.

## Features

- Vanilla JavaScript
- Tailwind v4.3.3
- Supabase as a Backend service

## Prerequisities

- npm

## Installation

- Clone this project:
  https://github.com/Elljens/Supabase.git

- Install dependencies:

```bash
npm init -y
```

```bash
npm install -D tailwindcss@^4 @tailwindcss/cli
```

## Running the project

- During development, run

```bash
npm runn dev
```

-When ready for production, run

```bash
npm run build
```
